快速开始
  1. 先去「设置」页配置 Alpaca API Key（必需）与可选的 Finnhub Key。
  2. 去「股票池」页选择一个 Universe（建议从 Core 或 Industry 开始，扫描更快）。
  3. 去「扫描」页运行分析，得到三频共振 + 机构多因子 的分层综合评分。
  4. 去「派生池」页从扫描结果中一键生成 Momentum / Quality / High RS / New Highs / CANSLIM候选 / Minervini候选 / 机构买入代理 池。
  5. 去「历史回溯」页输入任意历史日期，还原当天的信号状态（核心功能）。

🕐 单只股票历史回溯（核心功能）
输入历史日期，系统会把所有价格类指标截断到该日期重新计算，还原当天的三频共振与机构多因子状态。基本面/机构持仓类字段免费数据源只提供最新快照，回溯结果会明确标注「非时点数据」。
