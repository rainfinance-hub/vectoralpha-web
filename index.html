快速开始
  1. 先去「设置」页配置 Alpaca API Key（必需）与可选的 Finnhub Key。
  2. 去「股票池」页选择一个 Universe（建议从 Core 或 Industry 开始，扫描更快）。
  3. 去「扫描」页运行分析，得到三频共振 + 机构多因子 的分层综合评分。
  4. 去「派生池」页从扫描结果中一键生成 Momentum / Quality / High RS / New Highs / CANSLIM候选 / Minervini候选 / 机构买入代理 池。
  5. 去「历史回溯」页输入任意历史日期，还原当天的信号状态（核心功能）。

🕐 单只股票历史回溯（核心功能）
输入历史日期，系统会把所有价格类指标截断到该日期重新计算，还原当天的三频共振与机构多因子状态。基本面/机构持仓类字段免费数据源只提供最新快照，回溯结果会明确标注「非时点数据」。

Master Universe 同步 （V2 第二阶段新增）
"全量同步"从 Alpaca 拉取当前全部可交易美股列表(通常上万只)写入 master_universe 表，作为 Full Tradable Universe 的真实底表——但这一步只有 symbol/公司名/交易所等基础字段，没有市值/板块/RS等评分字段。评分字段会随着你实际扫描/回溯逐步补全("扫到哪只，哪只的数据就更全")，不是一次性伪造全量数据。

Dynamic Universe Builder
自由组合任意条件，自动查询 Master Universe 数据库生成股票池，例如"NASDAQ AND Market Cap > 10B AND RS > 80"。查询条件可以保存/修改/删除，下次直接复用。数据来自「设置」页的 Master Universe 同步 + 日常扫描积累，字段覆盖率会随使用逐步提高。

Signal Performance Dashboard
